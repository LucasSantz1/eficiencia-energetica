# Glossário

| Termo | O que significa |
| --- | --- |
| **kWh** (quilowatt-hora) | A unidade da conta de luz. Um aparelho de 1.000 W ligado por 1 hora gasta 1 kWh. |
| **W** (watt) | Potência do aparelho: quanto ele puxa de energia enquanto está ligado. Fica na etiqueta. |
| **BTU** | Medida da capacidade de resfriar do ar-condicionado (9.000, 12.000, 18.000...). Mais BTUs, mais potência. |
| **Inverter** | Ar-condicionado ou geladeira cujo motor diminui a velocidade em vez de ligar e desligar; gasta menos. |
| **Fator de ciclo** | Parte do tempo em que o motor de um aparelho trabalha de verdade (0 a 1). |
| **Distribuidora** | Empresa que leva a energia até a casa e manda a conta (ex.: Energisa, Enel, CEMIG). |
| **ANEEL** | Agência Nacional de Energia Elétrica: define as tarifas e as bandeiras. |
| **TE** (Tarifa de Energia) | Parte da tarifa que paga a energia em si. |
| **TUSD** (Tarifa de Uso do Sistema de Distribuição) | Parte da tarifa que paga o uso dos fios e da rede. |
| **B1 residencial** | Grupo de tarifa das casas. O sistema usa a tarifa convencional (preço igual o dia todo). |
| **Tarifa Branca** | Tarifa opcional com preço diferente por horário. Ainda não é calculada (HIS-204). |
| **Bandeira tarifária** | Sinal mensal do custo da energia: verde (sem adicional), amarela, vermelha 1 e 2, escassez hídrica. |
| **Consumo mínimo** (custo de disponibilidade) | O mínimo cobrado mesmo se a casa gastar menos: 30, 50 ou 100 kWh, conforme a ligação. |
| **Ligação** monofásica, bifásica, trifásica | Quantos fios de fase chegam na casa. Define o consumo mínimo. |
| **Tarifa Social** | Benefício que zera os primeiros 80 kWh do mês para famílias de baixa renda (Lei 15.235/2025). |
| **Desconto Social** | Desconto em contas de até 120 kWh para famílias com renda de ½ a 1 salário mínimo por pessoa. |
| **CadÚnico** | Cadastro Único do governo federal para programas sociais; feito no CRAS. |
| **CRAS** | Centro de Referência de Assistência Social da prefeitura. |
| **BPC** | Benefício de Prestação Continuada, pago a idosos e pessoas com deficiência de baixa renda. |
| **ICMS, PIS/COFINS** | Impostos na conta de luz. ICMS é estadual; PIS/COFINS são federais. |
| **CIP / iluminação pública** | Taxa municipal cobrada na conta de luz. |
| **INMETRO / PBE** | Instituto que faz a etiqueta de consumo (A a E) dos aparelhos, no Programa Brasileiro de Etiquetagem. |
| **PROCEL** | Programa Nacional de Conservação de Energia Elétrica; o Selo Procel marca os aparelhos mais econômicos. |
| **Conta de referência** | Uma conta de luz real informada pela família; o sistema usa o preço dela, já com impostos. |
| **Competência** | Mês de referência de uma conta (AAAA-MM). |
| **Plano de economia** | As dicas que a família marcou para seguir, com a nova conta calculada. |
| **PWA** | Site que pode ser instalado no celular como aplicativo. |
| **Camadas** | Forma de organizar o código do site em pastas com papéis separados (telas, componentes, dados), em que cada pasta só usa as de baixo. Um programa (`pnpm camadas`) confere isso a cada mudança. |
| **LGPD** | Lei Geral de Proteção de Dados (Lei 13.709/2018). |
| **RLS** (Row Level Security) | Regra do banco de dados que faz cada pessoa ver só os próprios dados (planejado no E4). |
| **SQL injection** | Ataque que tenta enganar o banco com texto malicioso; evitado com consultas parametrizadas. |
| **XSS** | Ataque que tenta rodar código na página de outra pessoa; evitado sem HTML cru e com CSP. |
